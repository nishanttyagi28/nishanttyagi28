# Nishant Tyagi

**Junior AI / GenAI Engineer | LLM Evaluation, RAG & Python Backends**

I build reliable LLM-powered applications, focusing on agent evaluation, RAG systems, and Python backends. My work emphasizes deterministic components, safety guardrails, testing harnesses, and practical integration of tools like Groq and local vector stores.

## Featured Projects

- **[AgentEval](https://github.com/nishanttyagi28/agenteval)**  
  CI-style evaluation & regression harness for LLM agents. Uses YAML golden test suites, 5 metrics (correctness, hallucination rate, tool-call accuracy, latency, cost), baseline comparison, and a Streamlit dashboard. Demonstrated on a multi-agent data analysis system.

- **[Agentic Data Analyst](https://github.com/nishanttyagi28/agentic-data-analyst)**  
  Multi-agent Streamlit application for natural language analysis of uploaded CSVs. Includes data quality gates, safe text-to-SQL (Groq Llama 3.3 70B), EDA/AutoML, statistics, forecasting, reports, and ChromaDB RAG for follow-ups. [Live Demo](https://agentic-data-analyst-uqjwnx2jwzd2pe9vosnffw.streamlit.app/)

- **[Scheme Saathi](https://github.com/nishanttyagi28/scheme-saathi)**  
  Government scheme eligibility navigator for Indian citizens. Rules-engine-first approach with deterministic logic, supplemented by local RAG (ChromaDB) and optional LangGraph agent (Groq) for conversational guidance. Built with FastAPI + Streamlit.

- **[Contract Shield](https://github.com/nishanttyagi28/contract-shield)**  
  Freelancer contract risk reviewer using deterministic rules + Groq for plain-language explanations. FastAPI backend with Streamlit interface for PDF/DOCX/TXT uploads and risk reports.
